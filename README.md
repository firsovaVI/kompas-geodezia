# КОМПАС ГЕОДЕЗИЯ — лендинг

Статическая HTML/CSS-вёрстка макета «Концепция 1 — Мягкий корпоративный» из Figma.

- `index.html` — разметка всех блоков (главный экран, услуги, задачи, этапы, гарантии, почему мы, команда, СРО, проекты и отзывы, FAQ, форма, футер)
- `styles.css` — стили, адаптив для планшета и телефона
- `assets/` — изображения и иконки, выгруженные из макета

Значения в квадратных скобках (`[N]`, `[цена]`, `[Имя Фамилия]` и т. д.) — плейсхолдеры из макета, их нужно заменить реальными данными.

Открыть: просто откройте `index.html` в браузере. Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
